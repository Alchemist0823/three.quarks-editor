

## THREE.QUARKS

Three.quarks es un motor de partículas rápido, potente y de propósito general para [three.js](https://threejs.org).

Este repositorio está archivado.

Accede a la última actualización desde **[Aquí](https://quarks.art)**.

### Instalación

Incluye una biblioteca de runtime principal y un **editor de sistemas de partículas**.

#### Runtime Principal

```
npm install three.quarks
```

La biblioteca de runtime cuenta con una única dependencia de three.js.

Utiliza instanciación por GPU y tecnología de búferes entrelazados para maximizar el rendimiento.

La mayoría de los parámetros del sistema de partículas pueden introducirse como curvas Bézier. Para los parámetros de curva,
dispone de una tabla de búsqueda para obtener el mejor rendimiento.

#### Editor

El sistema de partículas incluye un editor de Bézier interno y un visor WYSIWYG del sistema de partículas.

#### Agradecimientos

Potenciado por Three.js, React y mui.
